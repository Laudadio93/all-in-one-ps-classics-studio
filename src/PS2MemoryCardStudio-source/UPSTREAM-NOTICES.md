# Upstream notices

The files in `engine/` are adapted from the PS2 Memory Card Manager project by Ross Ridge and the PS2 Memory Card Manager maintainers:

- Project: https://github.com/lawlmoeaung/ps2-memory-card-manager
- Original PS2 filesystem and save-format code by Ross Ridge, released into the public domain.
- The project is released under the Unlicense. The included `UPSTREAM-LICENSE.txt` contains its license text.

This application uses the upstream `ps2mc`, `ps2save`, `ps2mc_dir`, `ps2mc_ecc`, `round`, `sjistab`, and `lzari` modules to read and write PS2 card images and parse PSU, MAX, CodeBreaker, SharkPort/X-Port, and PS2 PSV saves. The desktop interface and card-size/template workflow are specific to PS2 Memory Card Studio.
